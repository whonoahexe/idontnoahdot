# idontnoahdot

My Arch + Hyprland setup, curated so a fresh install is one command. The rice is **Glyph**: [Nebelung-cloud/glyph-rice](https://github.com/Nebelung-cloud/glyph-rice), a Nothing OS–style Quickshell shell (black, white dots, one red), with my changes on top and the apps themed to match.

The end4 ([illogical-impulse](https://github.com/end-4/dots-hyprland)) rice this repo used to carry, with its matugen theming, end4-pC shell patch, boot splash and `rice-switch`, is kept at the [`end4-final`](https://github.com/whonoahexe/idontnoahdot/tree/end4-final) tag.

## Layout

| | Where | What |
|---|---|---|
| **Glyph** | [`glyph/`](glyph/) | the rice: upstream tag + my commits as patches, `user.lua` + `machine/` (this laptop's monitors and AC/battery watcher), Glyph's settings, the Spotify / Brave / Apostrophe / Strata themes. Its own [README](glyph/README.md) and `install.sh` |
| machine + apps | repo root | packages, `/etc` tweaks, helper scripts, app configs, the wallpaper |

## What's at the root

- `packages/`:
  - `glyph.txt`: what the rice needs (Hyprland, Quickshell, SDDM, PipeWire, kitty, fish…), kept by hand
  - `pacman.txt` / `aur.txt`: my apps, regenerated by `sync.sh`
  - `hardware.txt`: NVIDIA + ASUS, only on the same laptop model (ASUS TUF A15 FA506QM)
- `system/`:
  - `common`: gamemode, zram + sysctl, no auto-sleep on lid close, v4l2loopback, Bluetooth always pairable
  - `hardware`: Wi-Fi ASPM fix, NVIDIA power limit, NVIDIA in the initramfs + modeset, `/usr/local/bin/reboot-to-windows` + its sudo rule (Glyph's power menu TO WINDOWS)
  - `services.txt`: the services to enable
- `.local/bin` + `.config/systemd/user`: helper scripts and their user units:
  - `audio-watchdog`: restarts a hung PipeWire
  - `mouse-rgb-watch`: re-applies the mouse colour on replug
  - `gamemode-hook.sh`: GPU logging while gaming
  - `strata-patched-update`
  - the `gh` / `git-credential-gh-account` wrappers for per-folder GitHub accounts
- App configs:
  - `strata` (file manager settings + custom actions, and it's the system file picker via `xdg-desktop-portal`)
  - `mpv`, `MangoHud`, `brave-flags.conf`, `ghostty`, `fontconfig`, `mimeapps.list`, `.bashrc`, `.gitconfig`
- `Pictures/Wallpapers/city-night-street`: the wallpaper + its animated scene (Glyph plays it as a live wallpaper)

Not included on purpose: anything with credentials or session state (SSH, GPG, browser profiles, `gh`/`npm`/`tailscale` config, Strata's SSH hosts, etc.) and work tooling.

## Fresh install: one command

On a fresh Arch install (a user with sudo, NetworkManager, a network connection), run as that user:

```sh
bash <(curl -fsSL https://raw.githubusercontent.com/whonoahexe/idontnoahdot/master/bootstrap.sh)
```

Enter your password once, reboot when it says done, and pick Hyprland (not the UWSM entry) at the login screen. `bootstrap.sh` is safe to re-run; it skips what's already done. In order, it:

1. updates the system and installs `git`, `base-devel` and `yay`
2. clones this repo to `~/Projects/idontnoahdot`
3. installs the packages: `hardware.txt` first (+ `linux-headers`, on the same laptop model only), then `glyph.txt`, `pacman.txt`, `aur.txt`; plus the Google Sans Flex font
4. installs `system/` into `/etc` and `/usr/local/bin`, rebuilds the initramfs (NVIDIA modules) and enables `services.txt`; enables PipeWire / ydotool user units and adds you to `input`, `video`
5. runs `install.sh`: the root files into `$HOME`, file by file (existing ones backed up as `.bak-<timestamp>`), and the user units
6. runs `glyph/install.sh` ([details](glyph/README.md))
7. builds [Strata](https://github.com/lgse/strata) from the latest release with my patches in `strata/`, and makes it the system file picker
8. installs Claude Code

Then by hand: the Spotify / Brave / Night Tab steps that `glyph/install.sh` prints.

## Updating this repo

```sh
./sync.sh      # copies the live configs from $HOME in, regenerates packages/, system/, strata/ and glyph/
git diff       # review, then commit and push
```

What gets synced:
- `PATHS` at the top of `sync.sh` (and `SYSTEM_FILES` / `HARDWARE_FILES` for `system/`)
- `GLYPH_HOME` for `glyph/home`

Repo-only files are kept across a sync: `/etc/sudoers.d` can't be read without root, and the NVIDIA initramfs / modeset drop-ins were written for fresh installs. Private values that must never land in the repo are rewritten using find/replace rules in `~/.config/idontnoahdot/scrub.sed`, which is deliberately not in the repo (without it, the Strata patches aren't refreshed).
